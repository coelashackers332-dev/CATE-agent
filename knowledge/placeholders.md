# Knowledge passages for the ask_cathay tool

**These four passages are placeholders.** They are not Cathay policy and carry no facts. They exist so the tool,
the search and the tests have something to run on. Replace this file with real passages before any demo.

Format (the loader ignores everything above the first `##`):

    ## Title of the passage
    Source: link to the page on Cathay's website it was written from
    Checked: date a person checked it against that page (YYYY-MM-DD)
    Asks: ways a caller might put the question; separated by semicolons (searched, never read out)

    The answer in plain spoken words. One short paragraph, two or three sentences.

A passage without `Source`, `Checked` and a text is skipped, so nothing unsourced can be read out.
One file per topic keeps them easy to check; the loader reads every `.md` file in this folder.
